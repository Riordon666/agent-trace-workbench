## Cross-platform blocker

`v0.2.0` calls `commandExists('openssl')`; the helper's default argument is `['--version']`. That executes `openssl --version`, while the portable OpenSSL command is `openssl version`.

The identical implementation later reached the three-platform package-smoke workflow. On Ubuntu Node `20.20.2`, [CI run `31571758003`](https://github.com/Riordon666/agent-trace-workbench/actions/runs/31571758003) installed the tarball successfully but `atw doctor` exited 1 with `OpenSSL: required by atw setup`. Commit `062b5f8` changed the call to `commandExists('openssl', ['version'])`; later Windows/macOS/Linux package-smoke matrices passed.

## Decision

Do **not** publish `agent-trace-workbench@0.2.0` to npm while claiming Windows, macOS, and Linux support. npm versions are immutable, so publishing first and correcting the artifact afterward is not an acceptable remediation.

Keep the existing GitHub Release as the historical Public Preview. The first npm release should be a later stable version that includes the portable OpenSSL fix and passes the current 9-job source matrix plus the three-OS isolated package-smoke matrix. Current `main` is still `0.3.0-dev.0`; preparing/tagging/publishing `v0.3.0` remains an explicit maintainer release decision.
